# Scripts de PHP5 comentados

➡️ Curso relacionado: **[Introducción a PHP5 a través de ejemplos](https://stahe.github.io/es-php5-juillet-2011/)**

---

## Descripción general

Este documento ofrece una **recopilación de scripts de PHP5** que abarcan diversas áreas de aplicación del lenguaje. No se trata de un curso exhaustivo, sino más bien de una **recopilación de ejemplos prácticos** destinados a ilustrar ciertas características de PHP5 y servir de base para la experimentación de los desarrolladores.

Los scripts presentados:
- están comentados directamente dentro del código;
- van acompañados de **su salida de consola**;
- a veces se complementan con **explicaciones adicionales** para ayudar a comprender mejor cómo funcionan.

El objetivo de este documento es ofrecer un **enfoque práctico del lenguaje PHP5**, basado en el estudio y el análisis de scripts.

---

## Público objetivo

Este documento está dirigido a desarrolladores que **ya hayan utilizado un lenguaje de scripting**, como:

- Perl;
- Python;
- VBScript;

Por lo tanto, se da por supuesto que el lector tiene **cierta familiaridad con los conceptos de scripting**.

Los lectores que no cuenten con esta experiencia previa deberían comenzar por un **curso completo sobre PHP** antes de utilizar esta recopilación de ejemplos.

---

## Método de lectura

Este documento requiere una **lectura activa**:

1. Lea el código del script.
2. Examine los comentarios incrustados.
3. Estudie los resultados de ejecución proporcionados.

Es la combinación de estos tres elementos lo que le permite comprender plenamente cada ejemplo.
