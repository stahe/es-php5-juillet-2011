    Escribiremos scripts PHP para trabajar con la base de datos. PHP cuenta con varias bibliotecas para gestionar bases de datos. Utilizaremos la biblioteca PDO (PHP Data Objects), que actúa como interfaz entre el código PHP y el SGBD:

    La biblioteca PDO permite que el script PHP se abstraiga de la naturaleza exacta del SGBD que se esté utilizando. Así, como se muestra arriba, el SGBD MySQL puede sustituirse por el SGBD Postgres con un impacto mínimo en el código del script PHP. Esta biblioteca no está disponible de forma predeterminada.     7.1. Conexión a una base de datos MySQL – 1 (mysql_01)

    Para conectarse a un SGBD, hay que crear un objeto PDO. El constructor admite varios parámetros:

    $dbh=new PDO($dsn,$user,$passwd,$driver_options)

    Los parámetros tienen los siguientes significados:

    $dsn
    (Data Source Name) es una cadena que especifica el tipo de SGBD y su ubicación en Internet. La cadena
    «mysql:host=localhost» indica que se trata de un DBMS MySQL que se ejecuta en el servidor local. Esta cadena
    puede incluir otros parámetros, como el puerto de escucha del SGBD y el nombre de la base de datos a la
    con la que desea conectarse: «mysql:host=localhost:port=3306:dbname=dbpersonnes».
    $user
    nombre de usuario del usuario que inicia sesión
    $passwd
    su contraseña
    $driver_options
    una matriz de opciones para el controlador del SGBD

    Solo es obligatorio el primer parámetro. El objeto creado de esta manera servirá entonces como vehículo para todas las operaciones realizadas en la base de datos a la que se haya conectado. Si no se ha podido crear el objeto PDO, se lanza una excepción PDOException.

    A continuación se muestra un ejemplo de conexión:

    
<?php
 
// connection to a MySql database
// user identity is (admpersonnes,nobody)
$ID = "admpersonnes";
$PWD = "nobody";
$HOTE = "localhost";
 
try {
  // connection
  $dbh = new PDO("mysql:host=$HOTE", $ID, $PWD);
  print "Connexion réussie\n";
  // closure
  $dbh = null;
} catch (PDOException $e) {
  print "Erreur : " . $e->getMessage() . "\n";
  exit();
}

    7.2. Creación de una tabla MySQL (mysql_02)

    
<?php
 
// connection to the MySql database
// user identity
$ID = "admpersonnes";
$PWD = "nobody";
// base identity
$DSN = "mysql:host=localhost;dbname=dbpersonnes";
 
// connection
list($erreur, $connexion) = connecte($DSN, $ID, $PWD);
if ($erreur) {
  print "Erreur lors de la connexion à la base [$DSN] sous l'identité ($ID,$PWD) : $erreur\n";
  exit;
}
 
// delete the people table if it exists
$requête = "drop table personnes";
$erreur = exécuteRequête($connexion, $requête);
//was there a mistake?
if ($erreur)
  print "$requête : Erreur ($erreur)\n";
else
  print "$requête: Exécution réussie\n";
// create people table
$requête = "create table personnes (prenom varchar(30) NOT NULL, nom varchar(30) NOT NULL, age integer NOT NULL, primary key(nom,prenom))";
$erreur = exécuteRequête($connexion, $requête);
//was there a mistake?
if ($erreur)
  print "$requête : Erreur ($erreur)\n";
else
  print "$requête: Exécution réussie\n";
// disconnect and exit
déconnecte($connexion);
exit;
 
// ---------------------------------------------------------------------------------
function connecte($dsn, $login, $pwd) {
  // connects ($login,$pwd) to base $dsn
  // returns the connection id and an error code
  try {
    // connection
    $dbh = new PDO($dsn, $login, $pwd);
    // error-free return
    return array("", $dbh);
  } catch (PDOException $e) {
    // return with error
    return array($e->getMessage(), null);
  }
}
 
// ---------------------------------------------------------------------------------
function déconnecte($connexion) {
  // closes the connection identified by $connexion
  $connexion = null;
}
 
// ---------------------------------------------------------------------------------
function exécuteRequête($connexion, $sql) {
  // executes the $sql request on the $connexion connection
  try {
    $connexion->exec($sql);
    // error-free return
    return "";
  } catch (PDOException $e) {
    // return with error
    return $e->getMessage();
  }
}

    Comentarios

    • Líneas 38–50: La función connect establece una conexión con un sistema de gestión de bases de datos (SGBD). Devuelve una matriz ($error, $connection*) donde $connection* es la conexión establecida o null si no se ha podido establecer la conexión. En este último caso, $error contiene un mensaje de error.
    • Líneas 53–56: La función *disconnect* cierra una conexión
    • Línea 59: La función *executeQuery permite ejecutar una instrucción SQL en una conexión. La conexión es un objeto PDO. El método utilizado para ejecutar una instrucción SQL en un objeto PDO es el método exec* (línea 63). La ejecución de la consulta puede lanzar una excepción PDOException. Por lo tanto, esto se gestiona. La función devuelve un mensaje de error si se produce un error; de lo contrario, devuelve una cadena vacía.

function exécuterCommandes($connexion, $SQL, $suivi=0, $arrêt=1) {
  // uses the $connexion connection
  // executes the SQL commands contained in the $SQL text file
  // this is a file of SQL commands to be executed one per line
  // if $suivi=1 then each execution of a SQL order is displayed as a success or failure
  // if $arrêt=1, the function stops on the 1st error encountered, otherwise it executes all sql commands
  // the function returns an array (nb of errors, error1, error2, ...)
 
  // check for the presence of the $SQL file
  if (! file_exists($SQL))
    return array(1, "Le fichier $SQL n'existe pas");
 
  // execution of SQL queries contained in $SQL
  // we put them in a table
  $requêtes = file($SQL);
  // we run them - initially no errors
  $erreurs = array(0);
  for ($i = 0; $i < count($requêtes); $i++) {
    //do we have an empty query
    if (preg_match("/^\s*$/", $requêtes[$i]))
      continue;
    // execute query $i
    $erreur = exécuteRequête($connexion, $requêtes[$i]);
    //was there a mistake?
    if ($erreur) {
      // one more mistake
      $erreurs[0]++;
      // error msg
      $msg = "$requêtes[$i] : Erreur ($erreur)\n";
      $erreurs[] = $msg;
      // screen tracking or not?
      if ($suivi)
        print "$msg\n";
      // shall we stop?
      if ($arrêt)
        return $erreurs;
    } else
    if ($suivi)
      print "$requêtes[$i] : Exécution réussie\n";
  }//for
  // return
  return $erreurs;
}

    7.4. Ejecución de consultas SQL arbitrarias (mysql_04)

    El siguiente script muestra la ejecución de comandos SQL desde el siguiente archivo de texto [sql.txt]:

    select * from personnes
select nom,prenom from personnes order by nom asc, prenom desc
select * from personnes where age between 20 and 40 order by age desc, nom asc, prenom asc
insert into personnes values('Josette','Bruneau',46)
update personnes set age=47 where nom='Bruneau'
select * from personnes where nom='Bruneau'
delete from personnes where nom='Bruneau'
select * from personnes where nom='Bruneau'
xselect * from personnes where nom='Bruneau'

    Entre estas sentencias SQL, se encuentra la sentencia SELECT, que devuelve resultados de la base de datos; las sentencias INSERT, UPDATE y DELETE, que modifican la base de datos sin devolver resultados; y, por último, sentencias no válidas como la última (xselect).

// ---------------------------------------------------------------------------------
function exécuteRequête($connexion, $sql) {
  // executes the $sql request on the $connexion connection
  // returns an array of 2 elements ($erreur,$résultat)
 
  // determine whether it's a select or not
  $commande = "";
  if (preg_match("/^\s*(\S+)/", $sql, $champs)) {
    $commande = $champs[0];
  }
  // order processing
  try {
    if (strtolower($commande) == "select") {
      $res = $connexion->query($sql);
    } else {
      $res = $connexion->exec($sql);
      if($res===FALSE){
        $info=$connexion->errorInfo();
        return array($info[2],null);
      }
    }
    // error-free return
    return array("", $res);
  } catch (PDOException $e) {
    // return with error
    return array($e->getMessage(), null);
  }
}
 
// ---------------------------------------------------------------------------------
function exécuterCommandes($connexion, $SQL, $suivi=0, $arrêt=1) {
  // uses the $connexion connection
  // executes the SQL commands contained in the $SQL text file
  // this is a file of SQL commands to be executed one per line
  // if $suivi=1 then each execution of a SQL order is displayed as a success or failure
  // if $arrêt=1, the function stops on the 1st error encountered, otherwise it executes all sql commands
  // the function returns an array (nb of errors, error1, error2, ...)
  // check for the presence of the $SQL file
  if (!file_exists($SQL))
    return array(1, "Le fichier $SQL n'existe pas");
 
  // execution of SQL queries contained in $TEXTE
  // we put them in a table
  $requêtes = file($SQL);
  // we run them - initially no errors
  $erreurs = array(0);
  for ($i = 0; $i < count($requêtes); $i++) {
    //do we have an empty query
    if (preg_match("/^\s*$/", $requêtes[$i]))
      continue;
    // execute query $i
    list($erreur, $res) = exécuteRequête($connexion, $requêtes[$i]);
    //was there a mistake?
    if ($erreur) {
      // one more mistake
      $erreurs[0]++;
      // error msg
      $msg = "$requêtes[$i] : Erreur ($erreur)\n";
      $erreurs[] = $msg;
      // screen tracking or not?
      if ($suivi)
        print "$msg\n";
      // shall we stop?
      if ($arrêt)
        return $erreurs;
    } else
    if ($suivi) {
      print "$requêtes[$i] : Exécution réussie\n";
      // information on the result of the query
      afficherInfos($res);
    }
  }//for
  // return
  return $erreurs;
}
 
// ---------------------------------------------------------------------------------
function afficherInfos($résultat) {
  // displays the $résultat result of an sql query
  // was it a select?
  if ($résultat instanceof PDOStatement) {
    // displays field names
    $titre = "";
    $nbColonnes = $résultat->columnCount();
    for ($i = 0; $i < $nbColonnes; $i++) {
      $infos = $résultat->getColumnMeta($i);
      $titre.=$infos['name'] . ",";
    }
    // remove the last character ,
    $titre = substr($titre, 0, strlen($titre) - 1);
    // displays the list of fields
    print "$titre\n";
    // dividing line
    $séparateurs = "";
    for ($i = 0; $i < strlen($titre); $i++) {
      $séparateurs.="-";
    }
    print "$séparateurs\n";
    // data
    foreach ($résultat as $ligne) {
      $data = "";
      for ($i = 0; $i < $nbColonnes; $i++) {
        $data.=$ligne[$i] . ",";
      }
 
      // remove the last character ,
      $data = substr($data, 0, strlen($data) - 1);
      // on affiche
      print "$data\n";
    }
  } else {
    // it wasn't a select
    print " $résultat lignes(s) a (ont) été modifiée(s)\n";
  }
}

    Comentarios

    Cada comando del archivo de texto [sql.txt] se ejecuta mediante la función exécuteRequête en la línea 43.

    • Línea 43: Los dos parámetros de la función son la conexión ($connexion) en la que se van a ejecutar los comandos SQL y el comando SQL ($sql) que se va a ejecutar. La función devuelve una matriz de dos valores ($erreur, $résultat) donde
      • $error es un mensaje de error, que puede estar vacío si no se ha producido ningún error
      • $result: el resultado devuelto al ejecutar la instrucción SQL. Este resultado varía dependiendo de si la instrucción es una instrucción SELECT o una instrucción INSERT, UPDATE o DELETE.
    • Líneas 48–51: Recuperamos el primer elemento de la instrucción SQL para determinar si se trata de una instrucción SELECT o de una instrucción INSERT, UPDATE o DELETE.
    • Línea 55: en el caso de una instrucción SELECT, se ejecuta utilizando el método [PDO]->query("SELECT statement"). El resultado devuelto es un objeto PDOStatement.
    • Línea 57: En el caso de una instrucción INSERT, UPDATE o DELETE, esta se ejecuta mediante el método [PDO]->exec("instrucción SQL"). El resultado devuelto es el número de filas modificadas por la instrucción SQL. Por lo tanto, si una instrucción SQL DELETE elimina dos filas, el resultado devuelto es el número entero 2. Si se produce un error durante la ejecución, el resultado devuelto es el valor booleano false. En este caso, el método [PDO]->errorinfo() proporciona información sobre el error en forma de una matriz de valores. El elemento en el índice 2 de esta matriz es el mensaje de error.
    • líneas 58–60: gestión de cualquier error de la operación [PDO]->exec("instrucción SQL").
    • Líneas 65–68: gestión de cualquier excepción
    • Línea 72: La función executeCommands ejecuta los comandos SQL almacenados en el archivo de texto *$SQL* en la conexión *$connection*. Este es un código que ya hemos visto, con una pequeña diferencia: la línea 111.
    • Línea 111: La función executeQuery devolvió una matriz (*$error*, *$result*), donde $result* es el resultado de ejecutar un comando SQL. Este resultado varía dependiendo de si el comando SQL era una instrucción SELECT* o una instrucción INSERT*, UPDATE* o DELETE*. La función displayInfo* muestra información sobre este resultado.
    • Línea 122: Si la instrucción SQL era una instrucción SELECT, el resultado es de tipo PDOStatement. Este tipo representa una tabla compuesta por filas y columnas.
    • Línea 125: el método [PDOStatement]->getColumnCount() devuelve el número de columnas de la tabla resultante de la instrucción SELECT
    • Línea 127: El método [PDOStatement]->getMeta(i) devuelve un diccionario con información sobre la columna i de la tabla de resultados de la instrucción SELECT. En este diccionario, el valor asociado a la clave «name» es el nombre de la columna.
    • Líneas 127–129: Los nombres de las columnas de la tabla de resultados de SELECT se concatenan en una cadena.
    • Líneas 141–145: Se puede iterar sobre un objeto PDOStatement utilizando un bucle foreach. En cada iteración, el elemento devuelto es una fila de la tabla de resultados de la instrucción SELECT en forma de una matriz de valores que representan los valores de las distintas columnas de la fila. Mostramos todos estos valores utilizando un bucle for.
    • Línea 154: El resultado de ejecutar una instrucción INSERT, UPDATE o DELETE es el número de filas modificadas por la instrucción.
